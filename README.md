# CourtAtlas — Court Data Analysis

Interactive US state court research website.

Live website: https://lois4801.github.io/court_data_analysis/

## Deployment
GitHub Pages serves the main branch root. Edit index.html and assets/ to update the live website. No build step required.

## Data
Official NCSC sources are cited beside the charts. Preliminary figures and hypothetical capacity scenarios are clearly labeled. Image credits and license links are included in the website footer.
